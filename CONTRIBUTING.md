# Contributing

Thanks for helping improve Vue Hand Note.

## Development

1. Fork and clone the repository.
2. Install dependencies with `npm install`.
3. Start the playground with `npm run dev`.
4. Make a focused change and add or update documentation when needed.
5. Run `npm run typecheck`, `npm run build`, and `npm run build:demo`.
6. Open a pull request with a clear description and before/after screenshots for visual changes.

## Guidelines

- Keep the public component API small and backwards compatible.
- Preserve keyboard and screen-reader behavior.
- Avoid adding runtime dependencies unless they provide substantial value.
- Use the existing direction and color types instead of duplicating values.
- Keep generated files and local environment values out of commits.
